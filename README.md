# Dựng video — skill Claude Code

Skill tự dựng video dọc tiếng Việt (TikTok, Reels, Shorts) từ clip quay điện thoại. **Cần mã bản quyền** — liên hệ người bán.

## Cài đặt (làm 1 lần)
Cần: máy Mac hoặc Windows 10/11, ứng dụng **Claude** trên máy tính (tab **Code**) hoặc Claude Code, ổ đĩa trống ≥ 5 GB.

1. Mở Claude Code, gõ lần lượt:
   ```
   /plugin marketplace add yenphatchina-commits/dung-video-viet
   /plugin install dung-video@dung-video-viet
   ```
2. **Bật tự cập nhật (1 lần):** gõ `/plugin` → **Marketplaces** → `dung-video-viet` → chọn bật **tự cập nhật (auto-update)**.
   Từ đó mỗi khi có bản mới, máy tự lấy về.
3. Khởi động lại Claude Code, rồi gõ: **cài đặt dựng video**
4. Gõ: **kích hoạt mã** và dán mã nhận khi mua.
5. Gõ: **kiểm tra máy** — tất cả ✅ là xong.

## Cập nhật
Đã bật tự cập nhật thì không cần làm gì. Chưa bật: gõ `/plugin` → **Marketplaces** → `dung-video-viet` → **Update**.
Skill cũng tự nhắc khi có bản mới.
Hồ sơ kênh, mã bản quyền và video đã làm không bị mất khi cập nhật.

## Hướng dẫn dùng
